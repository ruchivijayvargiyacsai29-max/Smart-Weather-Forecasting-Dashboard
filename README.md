
# Weather Detection App

A simple, elegant weather application built using **JavaScript**, **HTML**, and **CSS**. It fetches real-time weather data from the WeatherAPI and displays the current weather conditions along with a 3-day forecast for any city the user enters.

---

## 🌟 Features

- Search weather by city name
- Real-time weather information:
  - Temperature
  - Feels like
  - Condition (sunny, rain, etc.)
  - Humidity
  - Wind speed
  - Air Quality (PM2.5)
- Weather icons and dynamic background image based on current condition
- 3-day forecast with temperatures and icons
- Responsive and user-friendly design

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- [WeatherAPI](https://www.weatherapi.com/) – free weather data provider
- Unsplash (for dynamic weather background images)

---

## 🚀 How to Run the App

1. Clone or download this repository.
2. Make sure all 3 files are in the same folder:
   - `index.html`
   - `style.css`
   - `script.js`
3. Open `index.html` in any modern browser (Chrome, Firefox, Edge).
4. Enter a city name (e.g., London, New York, Delhi) and click **"Get Weather"**.

## 📌 Notes

- API Key used is from WeatherAPI and has limited requests per day.
- The app uses `fetch()` to retrieve data and dynamically updates the DOM.
- No frameworks were used – this is built with pure JavaScript.
